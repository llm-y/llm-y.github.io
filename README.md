# llm-y.github.io

Landing page [`agent`](https://github.com/llm-y/agent) (perintah `llmy`): instalasi dan manual.
Tayang di <https://ll.my.id>. Dibuat dengan [CrootJS](https://croot.js.org/), tanpa build.

- `index.html`, `style.css`, `script.js`: halaman utama. Ikuti [konvensi CrootJS](https://croot.js.org/docs/conventions).
- `install.sh`, `install.ps1`: pemasang dari GitHub Release.

Bila opsi atau perintah `llmy` berubah, perbarui juga manual di `index.html`.

```sh
python3 -m http.server
```
